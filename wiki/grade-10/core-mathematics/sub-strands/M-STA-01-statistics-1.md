# M-STA-01: Statistics I

**Inquiry questions:** What is statistics? How do we represent data? How do we use statistics
in day-to-day life?

## Curriculum alignment

The design covers collecting data from real-life sources; frequency tables for grouped and
ungrouped data; mean, mode, and median for both; histograms and frequency polygons; and
interpreting representations for informed decision-making. The source design indicates 16
lessons for this sub-strand.

**Concepts:** population, sample, data source, discrete/continuous data, frequency, class
interval, class boundary, modal class, mean, median, histogram, frequency polygon, interpretation.

**CBC emphasis:** critical thinking and problem solving, self-efficacy, digital literacy,
communication and collaboration; integrity, unity, and love; decision making and parental
engagement.

## Teacher pack

### Learning sequence

1. Start with a question that can be answered from data. Identify source, population, sample,
   variable, and an ethical/safe collection method.
2. Tally ungrouped observations and build a frequency distribution. For grouped data, choose
   sensible, non-overlapping class intervals and record class width.
3. Calculate mean, mode, and median. For grouped data, use class midpoints for an estimate and
   name the modal class; do not present an estimate as an exact raw-data mean.
4. Draw histograms (including unequal class widths where required) and frequency polygons.
   Read peaks, gaps, spread, and comparisons before making a decision.

### Low-resource activity

Collect a small, consent-safe class dataset such as mode of transport to school or number of
trees in sampled quadrats. Groups produce a table and graph, then write one conclusion and one
limitation.

### Kenyan context

Use pedestrian crossing availability, rainfall records, school attendance, or transport modes.
Discuss how a graph can inform a school or community action without exposing personal data.

### Check for understanding

- Design a collection question and identify its variable and source.
- Make grouped and ungrouped frequency tables with totals checked.
- Find mean, mode, and median and explain which is most informative in a skewed dataset.
- Interpret a histogram/frequency polygon with one supported conclusion and one caveat.

### Common misconceptions

- Calling every bar chart a histogram; histograms represent continuous class intervals.
- Leaving gaps between class intervals or double-counting boundary values.
- Treating the modal class as the mode of the raw data.
- Reading a correlation or pattern as proof of a cause.

## Worked example

For values `2, 3, 3, 4, 8`, the mean is `20/5=4`, the mode is `3`, and the median is `3`.
The mean is pulled upward by 8; the median better describes a typical central value here.
Show the sorted list before selecting the middle value.

## SMS teaching pack

**SMS 1/3:** `M-STA-01` Collect data ethically, tally frequencies, and check the total. Mean=sum/n; mode=most frequent; median=middle after sorting.

**SMS 2/3:** Grouped data uses class intervals and midpoints for an estimated mean. A histogram has touching bars for continuous intervals.

**SMS 3/3:** Try 2,3,3,4,8: find mean, mode and median. Which measure is pulled up by the outlier 8?
